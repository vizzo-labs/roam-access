Desktop search — three options.

Search and filters along the top, like Domain and realestate.com.au; the list beside the map; the place details are what differs. Open each one at 1440×900, then try 1280 and 1024. Every page has a small toolbar (bottom-left) to switch state and text size. The spec with trade-offs and a recommendation is spec.md.

Option A — drawer over the map recommended

Click a place and a 560 px drawer slides in beside the list, over the map. Verdict and actions first; Today, For your needs, Getting there, Reviews and More are folded rows whose summary already says the gist. The list and the map stay where they are, so you can compare places without losing your spot.

Option B — full place page

Click a place and it opens as a page, like a property listing: the phone's place page in a calm left column and a quiet right column with the photo, a mini-map, the address and the one main action. Back returns you to the list where you were.

Option C — one panel, as today

The place page replaces the list in the same panel (today's structure) under the new top bar. Least change. Included so the other two can be judged against the current shape.

What is real and what is sample. The 232 places, their kinds, suburbs, walking minutes from Manly Wharf and OpenStreetMap wheelchair tags are a read-only snapshot of the dev database. The dev database held no reviews, so twelve places carry sample community facts and quotes, each marked sample, only so every verdict state can be seen. The map ground is drawn, not tiles; the pins are at real coordinates.
  • The person is “Alex”: wheelchair or mobility aid + seats and rest spots. Change it with the “For:” chip.
  • The map mirrors the list on screen (one page of 10), hides overlapping pins instead of clustering, hides “No info yet” places at the overview zoom and offers “Search this area” — the behaviours the map thread is building.
  • Keyboard: Tab through top bar → chips → list → “Skip the map” → map controls and pins. A drawer or page takes focus to its heading; Escape or Close returns it to the card you came from.
